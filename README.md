# Prompt Organização

Um prompt de seis fases que transforma o Claude (ou o Codex, ou o Antigravity) no organizador da sua operação. Ele propõe uma estrutura de projetos, cria um Inbox para o que chega solto e escreve o `CLAUDE.md` ou `AGENTS.md` que manda a IA registrar tudo o que mudar.

## Como usar

1. Escolha a pasta onde você trabalha, ou crie uma vazia, por exemplo `minha-operacao`.
2. Abra a pasta no Claude Code (ou no Codex ou no Antigravity), copie o bloco "O prompt" do arquivo [PROMPT-ORGANIZACAO.md](PROMPT-ORGANIZACAO.md), cole na conversa e envie.
3. Responda as perguntas. Ele avança uma fase de cada vez.

## Aviso sobre dados sensíveis

Não cole senhas, chaves de acesso nem documentos de clientes ou pacientes. Use exemplos anonimizados.
